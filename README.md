# NamalskZenTreasurePhotos

Custom Namalsk photo set for [ZenTreasure](https://github.com/ZenarchistCode/ZenModPack/wiki/ZenTreasure), for servers running the [ZenTreasures Steam Workshop mod](https://steamcommunity.com/sharedfiles/filedetails/?id=3721974505).

These image files are intended for use with the photo clue / treasure systems in ZenTreasure, adapted for Namalsk.

## Notes:
* Install the files from this repository into your server's ZenTreasure photos folder, preserving the folder structure.
* These are intended as an extension to the original [ZenTreasure source repository](https://github.com/ZenarchistCode/ZenTreasure).
* Refer to the [ZenTreasure wiki documentation](https://github.com/ZenarchistCode/ZenModPack/wiki/ZenTreasure) for setup, configuration and usage details.
* The workshop page for the live mod is [here](https://steamcommunity.com/sharedfiles/filedetails/?id=3721974505).
